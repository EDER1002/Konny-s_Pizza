# Mockups de baja fidelidad — Konny’s Pizza

Esta carpeta contiene bocetos preliminares en escala de grises para representar la estructura y el recorrido principal de la aplicación antes de su diseño visual final.

## Cliente
`cliente/flujo-cliente.png` reúne cuatro pantallas conceptuales: inicio, selección de mesa, realización de reserva y confirmación.

## Administrador
`administrador/panel-administrativo.png` reúne seis pantallas conceptuales: inicio de sesión, mesas, horarios, reservas, carta y recomendaciones.

## Alcance
Estos mockups son referencias visuales de baja fidelidad, no capturas del sistema funcionando ni especificaciones exactas de todos los campos. Antes de presentarlos como diseño definitivo, deben contrastarse con la interfaz y los requisitos reales del proyecto.
